## Install

Copy a `.json` file from this folder into your T3 Code themes directory, or use the app's **Settings → Appearance → Import theme**. Activate with `Ctrl+Alt+A` in T3 Code or `t3 theme set <id>`.

The live-animated themes carry their CSS animation definitions inside the theme JSON; import the file as-is to preserve the animation.
